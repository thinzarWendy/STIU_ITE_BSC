# CSC220 Week 10 - Guided Lab 2 Solution

## Activity
Make the Student Directory Interactive.

## How to Run

1. Open this folder in VS Code.
2. Open a terminal in the project folder.
3. Install packages:

   npm install

4. Start the React application:

   npm run dev

5. Open the Local URL shown by Vite, normally:

   http://localhost:5173

## Main Requirements Covered

- Student array stored with useState
- Student data passed to StudentCard using props
- Controlled form inputs for name, major, and score
- Form submission with preventDefault()
- New students added with the spread operator
- Students deleted with filter()
- Student count updates automatically
- Stable unique ids using Date.now()
- Optional stretch: Show Passed Only / Show All Students
